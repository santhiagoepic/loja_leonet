# Manual Rápido do Sistema - Cliente

Este guia é destinado aos clientes da Loja Leonet. Siga as orientações para navegar e utilizar o sistema de forma simples.

## Como acessar
- Entre no site da Loja Leonet.
- Navegue pelas categorias e produtos disponíveis.
- Para comprar, clique no produto desejado e siga as instruções para registrar sua intenção de compra.
- Você pode criar uma conta para acompanhar suas intenções e avaliações.

## Funcionalidades principais
- **Buscar produtos:** Use a barra de busca para encontrar itens pelo nome.
- **Categorias:** Filtre produtos por categoria (Feminina, Masculina, Infantil, etc).
- **Detalhes do produto:** Veja fotos, descrição, preço e estoque.
- **Intenção de compra:** Clique em "Comprar" para registrar seu interesse. A equipe entrará em contato pelo WhatsApp.
- **Avaliações:** Após a compra, avalie o produto e deixe seu comentário.
- **Minha conta:** Acesse e edite seus dados, veja suas intenções e avaliações.

## Observações
- O sistema não realiza pagamento online, apenas registra a intenção de compra.
- O contato para finalizar a compra é feito via WhatsApp.
- Em caso de dúvidas, utilize o formulário de contato ou suporte.

---
Dúvidas? Procure a equipe da loja ou utilize o suporte no site.
