# Manual Rápido do Sistema - Admin

Este guia é destinado apenas para administradores da Loja Leoneth. Aqui você encontra um resumo das principais funções do painel administrativo.


## Acesso ao Painel
- Acesse `/admin` e faça login com seu usuário administrador.
- Para testar como cliente, use o botão "Logar como cliente de teste" no topo do painel.

## Funcionalidades do Painel

### Produtos
- Cadastre, edite e exclua produtos.
- Defina nome, descrição, preço, estoque, categoria, tipo e imagem.
- Marque produtos como "em destaque" para aparecerem na home.

### Categorias
- Organize os grupos exibidos na home e nos filtros.
- Crie, edite e exclua categorias.

### Tipos
- Gerencie os tipos de item usados nos produtos (ex: camiseta, calça).

### Banners
- Adicione banners para destaque visual na home.
- Ative ou desative banners conforme necessário.

### Avaliações
- Modere avaliações deixadas pelos clientes.
- Remova avaliações inadequadas.

### Permissões de Avaliação
- Controle quem pode avaliar produtos.
- (Página em desenvolvimento)

### Clientes
- Veja e edite perfis de clientes cadastrados.
- Atualize nome e telefone.

### Intenções de Compra
- Visualize pedidos de intenção de compra feitos pelos clientes.
- (Página em desenvolvimento)

## Navegação
- Use o botão "Voltar para o painel" para retornar ao menu principal.
- Use o botão "Encerrar sessão" para sair do painel admin.

## Observações
- Algumas páginas podem estar em desenvolvimento e exibir aviso.
- Sempre salve alterações antes de sair de uma tela de edição.
